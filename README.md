# FOSS Club Mpstme Official Website

The official website for FOSS Club MPSTME, built to showcase the club's events, team, and activities to students and visitors.

## Tech Stack

- React
- Vite
- React Router DOM
- Framer Motion
- Lucide React
- React Icons

## Folder Structure

```
foss-mpstme-website/
├── public/
│   ├── team/
│   ├── events/
│   └── foss-logos/
└── src/
    ├── components/
    ├── data/
    ├── pages/
    ├── App.jsx
    ├── main.jsx
    └── index.css
```

## Installation

Install the project dependencies:

```bash
npm install
```

Install React Router DOM and Framer Motion:

```bash
npm install react-router-dom framer-motion
```

## Running Locally

Start the development server:

```bash
npm run dev
```

The app will be running at [http://localhost:5173](http://localhost:5173)
